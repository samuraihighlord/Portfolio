# Frame Hashira — Portfolio

One-page portfolio site for Jafar (Frame Hashira): video editor, videographer, storyteller.

- `index.html` — page structure (Home, About, Contact sections)
- `style.css` — styles, animations, responsive layout
- `script.js` — **edit the `CONFIG` block at the top** to change video posts, social links and your X user ID
- `assets/` — images and icons

Plain HTML/CSS/JS, no build step.
